# Blink landing page

A single-file, dependency-free landing page for Blink.

## Preview

Open `index.html` in a browser:

```bash
open index.html
```

It works from the filesystem and respects light/dark mode, reduced motion, and
keyboard focus.

## Deploy

Upload the contents of this folder to any static host (GitHub Pages, Cloudflare
Pages, Netlify, S3). `icon.png` is bundled so the page works when this folder is
the site root.

The download buttons point at:

```
https://github.com/HectorTorrez/nook-notes/releases/latest
```
